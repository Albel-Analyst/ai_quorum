# Quorum — руководство для команды

> Питч в одну строку: **агент, у которого нет реплик — только одна живая карточка и кнопки.**

Quorum живёт в треде, где команда что-то решает. Он не пишет в тред. У него одно сообщение — карточка решения —
и он его редактирует. Всё остальное: кнопки, ephemeral-сообщения, личные DM. Он структурирует, а не спорит:
вопрос, варианты, позиции, открытые вопросы, факты, дедлайн, решение, запись. Любая запись наружу и любой публичный
пинг — только после тапа человека.

## Быстрый старт (локально, без деплоя)

```bash
cp .env.example .env            # заполнить SLACK_BOT_TOKEN, SLACK_APP_TOKEN, OPENAI_API_KEY (EXA_KEY, JIRA_* — опционально)
make install                    # uv sync
make env                        # проверить все ключи живьём
make run                        # бот в Socket Mode с ноутбука (публичный URL не нужен)
# или в контейнере:
make up                         # docker compose up --build + логи
```

Настройка Slack-приложения — `docs/SLACK_APP.md` (манифест `docs/slack_manifest.yaml`). **Одно Slack-приложение = один
запущенный Quorum**: Socket Mode делит события между подключениями, второй инстанс (чужой ноутбук, под в кубере,
старый WALrus) молча забирает половину событий.

Без `OPENAI_API_KEY` бот запускается с детерминированным `FakeProvider` (`make fake`) — удобно править рендерер и кнопки.
`DEMO_TIME_SCALE=60` ускоряет таймеры в 60 раз (30-минутное «молчание» срабатывает через 30 с) — для демо.

## Как это устроено

```
Slack (Bolt, Socket Mode) ──normalize──▶ Event ──▶ Engine ──▶ CardState ──render──▶ Block Kit ──▶ chat.update
                                                     │  ▲
                                                     ▼  │  Extraction (strict schema)
                                                   LLM (state JSON + новые сообщения)
```

| Слой | Где | Что |
|---|---|---|
| Домен | `quorum/domain/models.py` | `CardState` — единственный источник правды карточки; `TrackedThread`; `DecisionMemory` |
| State machine | `quorum/domain/state_machine.py` | Framing → Deliberating → Voting → Decided → Recorded; Stalled/Parked/Expired/Superseded. `PHASE_CHANGE` — статусы, при которых карточка перепощивается в конец треда |
| Мерж | `quorum/core/merge.py` | Extraction → CardState: позиции, исправленные человеком, LLM не перезаписывает; id вариантов стабильны; верификация фактов сохраняется |
| Движок | `quorum/core/engine.py` | события, per-thread lock, коалесинг (4 с), кнопки/формы, запись, верификация, память, автопредложение, таймеры (`tick`) |
| LLM | `quorum/llm/` | `base.py` — протоколы и схемы; `openai_provider.py` — gpt-5.4-mini/gpt-5.4 через structured output; `fake.py` — оффлайн |
| Рендер | `quorum/render/blockkit.py`, `markdown.py` | CardState → Block Kit (детерминированно, тестируется без Slack); ADR-markdown |
| Платформа | `quorum/platform/base.py` | `ChatPlatform`: post_card / update_card / ephemeral / dm / open_form / fetch_thread…; `slack/adapter.py` — Bolt; `fake.py` — для тестов; `discord/` — место для второго адаптера |
| Плагины | `quorum/recorders/`, `quorum/verifier/` | Recorder: confluence / canvas / jira / markdown; Verifier: Exa. Каждый скрывается без ключа |
| Стор | `quorum/store/sqlite.py` | треды (JSON), журнал решений, дедуп `event_id`, кэш сообщений |

Словарь кнопок и форм между движком, рендерером и адаптером — `docs/CONTRACTS.md`. Меняешь кнопку — меняй там.

## Пользовательские пути (что должно работать в демо)

1. **Вход**: `@Quorum` в треде · шорткат «Track with Quorum» · реакция ⚖️ на корень. Бот забирает историю
   (`conversations.replies`) и сразу ставит карточку; через ~5 с LLM наполняет её.
2. **Спор**: карточка обновляется после каждого сообщения (коалесинг). «Моя позиция» → модалка: человек поправляет LLM.
3. **Факт**: LLM выделяет утверждения о внешнем мире → «Проверить» → Exa + LLM-судья → бейдж + 2–3 источника.
4. **Молчит ключевой человек**: вопрос адресован X, X молчит T минут / N чужих сообщений → один DM X-у
   [Открыть тред] [Это не ко мне]. Никогда дважды.
5. **Заглохло**: нет сообщений `STALL_HOURS` → Stalled, карточка показывает, что блокирует, автору DM.
   «Отложить» = почему и когда вернуться (DM в срок). Stalled `EXPIRE_HOURS` → Expired с перечнем открытого.
6. **Дедлайн**: из текста («до среды») или кнопкой; по наступлении голосование открывается само.
7. **Голосование**: кнопки по вариантам, переголосовать можно; все проголосовали / дедлайн → DM автору «подтверди».
   Решение фиксирует **[Подтвердить]** автора треда (снимок позиций ≠ решение).
8. **Запись**: [Записать] → ADR (контекст, варианты, решение, обоснование, несогласие, последствия, follow-ups) →
   Confluence / Canvas / Jira / markdown; финальная карточка `reply_broadcast` в канал.
9. **Память**: каждое решение — в журнале. Новое сообщение в канале → «противоречит ли решению?» → мини-карточка
   в тред [Ссылка] [Оспорить]. «Оспорить» открывает новый Quorum-тред; при подтверждении старое → Superseded.
   App Home — журнал решений.

## Правила разработки

- **LLM не пишет карточку.** Он возвращает `Extraction` по строгой схеме, код мержит и рендерит. Хочешь новый
  элемент на карточке → поле в `CardState` → мерж → рендер → тест на блоки.
- **Ничего публичного без тапа.** Автономно: правка карточки, DM. Тред-сообщение — только memory recall.
- **Failure handling виден пользователю**: LLM упал → карточка не меняется, футер «⚠️ последнее обновление не удалось»;
  Exa упал → «не удалось проверить»; Recorder упал → ретрай, потом markdown, потом markdown в DM.
- Тесты без Slack и без LLM: `FakePlatform` + `FakeProvider`. `make check` перед пушем (ruff + pytest).
- Строки интерфейса только через `quorum/i18n.py` (`QUORUM_LANG=en|ru`); контент карточки — на языке треда.
- Новый мессенджер = новый адаптер (`ChatPlatform`) + рендерер. Движок не трогаем.

## Тесты и отладка

```bash
make test                                    # всё оффлайн
QUORUM_LIVE_LLM=1 uv run pytest tests/test_llm_live.py    # живой вызов OpenAI
QUORUM_LIVE_EXA=1 uv run pytest tests/test_exa.py
LOG_LEVEL=DEBUG make run
sqlite3 data/quorum.db 'select key,status from threads'   # состояние тредов
```

Slack не доставляет `app_mention` на сообщения бота — команды проверяем живым пользователем. Сообщения в Slack
нельзя переместить: карточку правим на месте, а перепощиваем (со снятием старой) только при смене фазы.

## Скоуп

- **MVP (без него демо нет)**: упоминание → живая карточка → «Моя позиция» → голосование → подтверждение → ссылка на запись.
- **Второй слой**: DM молчащему, Stalled, дедлайн, память с recall.
- **Стретч**: ephemeral-предложение, Exa, Jira, App Home, Discord-адаптер.

Доступы — `docs/ACCESS.md`. Контракты модулей — `docs/CONTRACTS.md`.
